and nothing else.

## The entry (63 characters, one line)

> Just hired a tumor to help my son with math — he starts Monday!

## How it works

`main.ts` (Node 22, standard library only) writes the one-line text above to
`/output/entry.txt` (or `$ENTRY_OUTPUT` when set). No network, no input, no
dependencies — the text is a constant in the program.

Run it locally:

```sh
node main.ts
cat /output/entry.txt
```

## Why this slip

`tutor` → `tumor` is a single-letter slip (t → m), so it reads as a real
autocorrect error rather than a written joke. The intended word is obvious
from context — someone hired to help a son with math is a tutor — and the
wrong word lands twice: first as the hire itself, then again when the tumor
"starts Monday", as if it were an employee with a start date. The field's
257 submissions are saturated with meeting→mating, boss texts, grandma
texts, condoms at dinner, and wedding→weeding; tutor→tumor is a zero-hit
pair in the field, and the hire-for-the-kids angle is untouched.
